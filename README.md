# task-6-quaternions
Повороты в пространстве через кватернионы: класс `Quaternion` и поворот 3D-векторов.

## Клонирование репозитория
```
https://github.com/Python-polytech/task-6-quaternions.git
cd task-6-quaternions
```

## Как решается задача

Кватернион `q = w + xi + yj + zk` реализован классом `Quaternion`
(`src/quaternions/quaternion.py`):

- сложение (покомпонентно), умножение (произведение Гамильтона, некоммутативное),
  сопряжение, норма, обратный кватернион `q⁻¹ = conj(q) / |q|²`;
- `Quaternion.from_axis_angle(axis, angle)` строит кватернион поворота вокруг оси `axis`
  на угол `angle` (в радианах): `q = (cos(θ/2), sin(θ/2)·û)`, где `û` — нормированная ось;
- `q.rotate(v)` поворачивает вектор: `v` представляется чистым кватернионом `(0, vx, vy, vz)`,
  вычисляется `q·v·q⁻¹`, результатом являются его компоненты `x, y, z`;
- композиция поворотов: сначала `q1`, затем `q2` — это `q2 * q1`.

Тесты (`tests/test_quaternion.py`) проверяют арифметику, повороты на 90°/180° вокруг осей,
композицию, сохранение длины вектора и ошибки (нулевая ось, обращение нулевого кватерниона).

## Как запустить

Нужен Python 3.10+.

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -e ".[dev]"          # ставит пакет и pytest из pyproject.toml
```

Пример работы:

```bash
python3 src/example.py
```

Ожидаемый вывод:

```
Вектор: (1, 0, 0)
Поворот на 90° вокруг Z: (0.0, 1.0, 0.0)
Затем поворот на 90° вокруг X: (0.0, 0.0, 1.0)
Композиция q_x * q_z за один шаг: (0.0, 0.0, 1.0)
```

Тесты:

```bash
pytest -v
```
